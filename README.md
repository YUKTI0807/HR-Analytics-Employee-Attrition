## Project Overview

This project focuses on analyzing employee attrition to understand why employees leave an organization.

I used Python, Pandas, SQL, MySQL, and Power BI to clean data, perform analysis, identify attrition patterns, and create an interactive dashboard.

## Project Objectives

- Analyze employee attrition patterns.
- Identify factors associated with employees leaving the company.
- Analyze attrition by department, job role, age, salary, and experience.
- Find useful insights using SQL queries.
- Create an interactive Power BI dashboard.
- Provide business recommendations to improve employee retention.

## Tools & Technologies

- **Python:** Data analysis
- **Pandas & NumPy:** Data cleaning and manipulation
- **Matplotlib:** Data visualization
- **Jupyter Notebook:** Python analysis
- **MySQL:** SQL queries and analysis
- **Power BI:** Interactive dashboard

## Project Workflow

1. **Business Problem:** Understand the employee attrition problem and define project objectives.
2. **Dataset Understanding:** Explore the dataset, columns, data types, and employee information.
3. **Data Cleaning:** Handle duplicate records and remove unnecessary columns.
4. **Exploratory Data Analysis (EDA):** Analyze employee attrition patterns using Python and Pandas.
5. **SQL Analysis:** Perform SQL queries to analyze attrition by department, job role, overtime, salary, and other factors.
6. **Power BI Dashboard:** Create an interactive dashboard with KPIs and visualizations.
7. **Business Insights:** Identify important findings and provide recommendations to improve employee retention.

## Key Analysis Areas

- Overall Employee Attrition
- Attrition by Department

- Attrition by Salary

## Key Findings

- Total employees: 1,470
- Employees who left: 237
- Overall attrition rate: 16.12%
- Average employee age: 36.92 years
- Average monthly income: 6,502.93

The analysis helps identify employee groups and workplace factors associated with higher attrition.

## Business Recommendations

- Improve employee salary and benefits.
- Reduce excessive overtime and workload.
- Provide career growth and promotion opportunities.
- Improve employee satisfaction and work-life balance.
- Introduce training and mentoring programs for new employees.
- Focus on departments and job roles with higher attrition.
